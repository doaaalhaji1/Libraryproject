🔙 Back-End Overview
The back-end of the application is developed using Laravel, a robust PHP framework that powers the core functionality. The back-end handles database management, API development, and authentication, ensuring secure and efficient operations for the app.

✨ Main Features
User authentication system (login, registration, password reset)

API endpoints for managing books, authors, categories, and users

Admin functionality for approving/denying borrow requests and confirming returns

Database models and migrations for consistent data structure

Integration with the front-end to fetch data via RESTful APIs

📦 Technologies Used
Laravel for the back-end framework

MySQL for database management

JWT Authentication for secure user authentication

RESTful APIs for client-server communication
